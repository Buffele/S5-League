## Installation sur l'autre ordinateur

Installer Git, Git LFS et Node.js 22.20.0, puis exécuter :

```sh
git lfs install
git clone https://github.com/Alkatarak/S5leaguePV.git
cd S5leaguePV
git lfs pull
npm ci
npm run build
npm run dev -- --port 5174 --strictPort
```

Ouvrir http://127.0.0.1:5174/ et choisir ce dossier dans Codex. Il n'est pas
nécessaire de recréer le compte Windows ou le chemin du PC d'origine.
Blender sert à éditer les sources 3D ; Python et .NET servent à certains outils
d'extraction et de capture. Ils ne sont pas nécessaires au lancement du jeu.

L'installation externe complète de S5Runtime n'appartient pas au dépôt. Elle reste
nécessaire pour effectuer de nouvelles captures dans S5Runtime ou extraire des
ressources non encore récupérées. Les ressources déjà intégrées sont incluses.
